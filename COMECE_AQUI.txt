PARA PUBLICAR
1) Abra docs\DEPLOY_GRATIS_PASSO_A_PASSO.md
2) Crie o projeto gratuito no Supabase
3) Execute supabase\01_schema.sql
4) Execute supabase\02_seed_via_verde.sql
5) Publique esta pasta num repositório privado do GitHub
6) Conecte o repositório ao Render usando render.yaml
7) Defina as variáveis secretas
8) Abra a URL do site e entre como pedro.massoli

PARA ALTERAR PELO VS CODE
- ABRIR_NO_VSCODE.bat
- TESTAR_PROJETO.bat
- ATUALIZAR_SITE.bat

IMPORTANTE
Nunca envie o arquivo .env nem a SUPABASE_SERVICE_ROLE_KEY para o GitHub.
