CAR 1.4.0: integração inicial de Crédito Rural, Banco Central e MapBiomas.

• Nova aba “Crédito Rural” dentro da análise do CAR. Ela concentra informações públicas relacionadas ao crédito e mantém separadas as fontes que realmente identificam o CAR daquelas que são apenas contexto agregado.

• Integração com o Monitor do Crédito Rural do MapBiomas: o Via Verde copia automaticamente o CAR e abre a plataforma oficial para consulta detalhada das operações e glebas públicas disponíveis. A interface deixa explícito que ausência de operação pública não prova inexistência de financiamento.

• Integração com a Matriz de Dados do Crédito Rural (MDCR/SICOR) do Banco Central: o aplicativo tenta consultar automaticamente dados agregados de Custeio e Investimento por município/produto e apresenta finalidade, ano, produto, quantidade de contratos e valor. Esses números são identificados como contexto municipal e nunca como contratos do CAR.

• Integração autenticada com a API oficial MapBiomas Alerta v2. Em Configurações existe um novo cartão “MapBiomas Alerta”. O usuário conecta uma conta MapBiomas confirmada uma única vez. A senha é usada apenas para obter o Bearer Token e NÃO é salva pelo Via Verde; ficam salvos localmente apenas o token e o e-mail da conta.

• Com o MapBiomas Alerta conectado, cada consulta de CAR busca automaticamente a ruralProperty correspondente e mostra alertas vinculados ao imóvel: código, área, data de detecção, data de publicação, fontes e link para o laudo oficial.

• Os pontos dos alertas retornados pela API podem ser mostrados no mapa como uma camada “MapBiomas Alerta”.

• A nova aba possui atalhos para abrir o Monitor do Crédito Rural, dados públicos do BCB/SICOR, imóvel no MapBiomas Alerta e laudos individuais de alertas.

• Alertas, cruzamentos e dados de crédito são apresentados como informação para conferência. O Via Verde não classifica automaticamente uma operação como irregular e não trata a ausência de dados públicos como prova de inexistência de crédito.

• A versão não faz scraping de endpoints privados ou não documentados do Monitor do Crédito Rural. Operações/glebas individualizadas continuam sendo abertas na plataforma oficial, enquanto a automação direta usa somente API documentada do MapBiomas Alerta e API pública do Banco Central.

Consulta CAR, Nova consulta, abas compactas, mapa, glebas A/B/C, relevo, WorldCover, Temas SICAR, triagem ambiental, KML, histórico, relatórios, backup e atualização automática permanecem preservados.
